A lightweight native GNOME remote for Pioneer Elite and VSX receivers that use the IP control protocol on port 8102.

## About
This app was collaboratively developed (“vibe coded”) with Grok (xAI).  
It works with many Pioneer models from roughly 2011–2016 (SC-65, SC-67, SC-122x, VSX-112x, and similar).  
It is intended as a practical remote and as a template for other Pioneer receivers.

## Compatible Models
High confidence: SC-65, SC-63, SC-67, SC-68, SC-71, SC-72, SC-77, SC-79,  
SC-1223 / 1227 / 1228 / 1323 / 1522 / 1523 / 1527,  
VSX-1123 / 1124 / 1125 / 1128 / 1133 / 1325 / 1326,  
and most other VSX models of the same generation that respond on port 8102.

## Installation
1. Clone or download this repository.
2. Install dependencies: `sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1`
3. Run with: `python3 pioneer-remote-gnome.py`
